sequenceDiagram
    autonumber
    actor User as 👤 Customer
    participant UI as 🖥️ Chat Widget (app.js)
    participant API as 🌐 Flask API (app.py)
    participant Lock as 🔒 Session Lock Manager
    participant Norm as 🧠 Normalizer & Intent Resolver
    participant LLM as 🤖 Ollama (qwen2.5:32b)
    participant Filter as 🔍 Catalogue Filter (41-Catalogue)
    participant Comp as ✍️ Response Composer

    User->>UI: Types "i need a photo booth printer"
    Note over UI: Non-blocking UI (user input remains active)
    User->>UI: Types "sorry i want photo printer" (Correction)
    Note over UI: Debounces 1200ms -> bundles both inputs
    UI->>API: POST /api/chat {messages: ["...photo booth...", "...sorry photo printer..."]}
    
    API->>Lock: force_reset(session_id) & acquire_lock()
    Lock-->>API: Lock acquired (supersedes older pending turns)

    API->>Norm: normalize_category(combined_text)
    Note over Norm: Scans from bottom up -> Detects correction -> photography_large_format
    
    API->>LLM: _extract_semantic_features(prompt)
    LLM-->>Norm: Intent=correction, application=photography
    
    API->>Filter: filter_products(category="photography_large_format", reqs)
    Note over Filter: Filters SC-P models, excludes photo_booth and Citizen
    Filter-->>API: returns [SC-P700, SC-P900, SC-P5300...]
    
    API->>Comp: compose_response(context, verified_candidates)
    Comp-->>API: Grounded response asking compact vs large-format
    API->>Lock: release_lock(session_id)
    API-->>UI: 200 OK {reply, product_cards}
    UI->>User: Displays single coherent response addressing photo printer
